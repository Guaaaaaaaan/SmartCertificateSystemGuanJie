# Smart Certificate Verification & Student Records Management System

ASP.NET Core MVC final project for certificate verification and student records management.

## Features

- Role-based session login for Admin, Student, and Employer users.
- Public certificate verification by certificate ID, student name, and date of birth.
- Admin student record management with add, update, delete, search, and sorting.
- Admin course, module, enrollment, certificate, and file management.
- Student dashboard for certificates, transcripts, grades, GPA, and transcript download.
- Transcript PDF generation on demand from database records when no uploaded transcript file exists.
- SQLite database integration with EF Core, LINQ queries, and raw SQL examples.
- File upload support for certificate PDFs, transcript files, and student documents.
- xUnit tests for authentication, certificate verification, search/sort, file safety, GPA, course management, and transcript PDF generation.

## Tech Stack

- .NET 10 / ASP.NET Core MVC
- SQLite + EF Core
- Custom session authentication
- xUnit tests

## Run

```powershell
dotnet restore .\SmartCertificateSystem.slnx
dotnet run --project .\SmartCertificateSystem\SmartCertificateSystem.csproj
```

Open the URL shown by `dotnet run`, or use `http://localhost:5221` when launched with the included profile.

The app creates its local SQLite database at:

```text
SmartCertificateSystem/App_Data/smart_certificate.db
```

Seed data is inserted only when the database has no users. If an existing local database is already present, newly added seed accounts or certificates will not be reinserted automatically.

## Role Workflows

### Admin

After logging in as Admin, use the navigation links to:

- View dashboard counts for students, certificates, courses, and raw SQL student count.
- Manage students from `Students`.
- Generate a transcript for a student from `Students` with `Generate Transcript`.
- Manage courses, modules, and enrollments from `Courses`.
- Create certificate records from `Certificates`.
- Upload certificate PDFs, transcript files, or student documents from `Files`.

### Student

After logging in as a Student, use `My Records` to:

- View personal academic details, GPA, certificates, transcripts, and grades.
- Download transcript PDF files.
- Receive an on-demand generated transcript PDF when no uploaded transcript file exists.

### Employer

After logging in as Employer, use `Employer Verification Portal` to open the certificate verification page.

Certificate verification is also available publicly without login.

## Certificate and Transcript Generation

Certificate records are created by Admin from the `Certificates` page. A certificate record stores the certificate ID, award title, student, completion date, issue date, and status.

Transcript records are generated by Admin from the `Students` page. The system stores transcript data in the database, including grades and GPA.

Transcript files do not need to be seeded. When a user downloads a transcript:

- If an uploaded transcript file exists, the uploaded file is returned.
- If no uploaded file exists, the system generates a PDF from the transcript record on demand.

For certificate verification downloads, a valid certificate must be linked to a transcript record. The current `Generate Transcript` action links a newly generated transcript to the student's latest certificate when that certificate does not already have a transcript.
